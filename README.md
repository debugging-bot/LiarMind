# LiarMind (라이어마인드)

캐치마인드 + 라이어 게임을 결합한 Java 소켓 네트워크 게임 (네트워크프로그래밍 텀프로젝트)

- 서버: `LiarMindServer.java` (수업 예제 `JavaChatServer.java` 확장)
- 클라이언트: `LiarMindClientMain.java`, `LiarMindClientView.java` (수업 예제 확장, 팀원 B)
- 서버 테스트용: `LiarMindTestClient.java` (콘솔에서 명령어를 직접 입력)

## 실행 방법

1. `LiarMindServer` 실행 → 포트 확인(기본 30000) → `Server Start`
2. 클라이언트 여러 개 실행 → 닉네임, 서버 IP(같은 컴퓨터는 127.0.0.1), 포트 입력 후 접속

## 메시지 프로토콜

- 모든 메시지는 `DataOutputStream.writeUTF()` / `DataInputStream.readUTF()`로 문자열 한 개씩 주고받는다.
- 형식: `/명령어 내용` (명령어와 내용은 공백 하나로 구분, 내용 안에는 공백이 있어도 됨)
- 닉네임에는 공백과 쉼표를 쓸 수 없다 (최대 10자).

### 1주차 (구현 완료)

| 메시지 | 방향 | 설명 |
| --- | --- | --- |
| `/login 닉네임` | 클라이언트 → 서버 | 접속 직후 반드시 첫 메시지로 보낸다 |
| `/loginok 닉네임` | 서버 → 본인 | 접속 성공 |
| `/reject 이유` | 서버 → 본인 | 접속 거부 후 서버가 연결을 끊는다. 이유: `empty` 빈 이름, `invalid` 공백·쉼표 포함, `toolong` 10자 초과, `duplicate` 중복 닉네임, `full` 8명 초과, `started` 게임 진행 중, `login_required` 첫 메시지가 /login이 아님 |
| `/users 이름1,이름2,...` | 서버 → 전체 | 접속자 목록. 순서 = 프로필 칸 순서, **첫 번째 이름이 방장**. 입장·퇴장 때마다 전송 |
| `/system 내용` | 서버 → 전체/본인 | 안내 문구 (입장, 퇴장 등). 채팅창에 표시 |
| `/chat 내용` | 클라이언트 → 서버 | 채팅 보내기 |
| `/chat 보낸이름 내용` | 서버 → 전체 | 채팅 받기 (보낸 사람 본인에게도 돌아옴) |
| `/exit` | 클라이언트 → 서버 | 정상 퇴장 (창을 그냥 닫아도 서버가 퇴장 처리함) |

### 2주차 이후 (예정)

| 메시지 | 방향 | 설명 |
| --- | --- | --- |
| `/draw x1 y1 x2 y2 색RGB 굵기` | 현재 차례 → 서버 → 전체 | 선분 하나 그리기 |
| `/clear` | 현재 차례 → 서버 → 전체 | 그림판 전체 지우기 |
| `/start 바퀴수 모드` | 방장 → 서버 | 게임 시작 |
| `/word 카테고리 제시어` | 서버 → 개별 | 제시어 전달 (라이어는 제시어 대신 `?` 또는 다른 단어) |
| `/turn 이름 바퀴 제한시간` | 서버 → 전체 | 그릴 차례 알림 |
| `/next` | 현재 차례 → 서버 | 다음 차례로 |
| `/votestart`, `/vote 이름` | 서버 → 전체, 클라이언트 → 서버 | 투표 시작, 투표 |
| `/guessstart 이름`, `/guess 단어` | 서버 → 전체, 라이어 → 서버 | 라이어 정답 기회 |
| `/result 승리팀 라이어 제시어` | 서버 → 전체 | 결과 (`LIAR`, `CITIZEN`, `CANCEL`) |
| `/score 이름:점수,...` | 서버 → 전체 | 점수 |
